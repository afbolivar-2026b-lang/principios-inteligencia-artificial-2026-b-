Falta conectar Firebase

Esta página está lista para guardar todo en Firebase, pero primero necesita los datos de tu proyecto. Edita el archivo y reemplaza el objeto firebaseConfig (cerca del inicio del bloque <script>) con la configuración que te da Firebase al crear un proyecto Web:

const firebaseConfig = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };

La consigues en Firebase Console → Configuración del proyecto → tus apps → SDK setup and configuration. También activa Firestore (modo producción o prueba) y configura sus reglas.
